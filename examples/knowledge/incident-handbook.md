# AI 工作流事件處理手冊

## 事件分級

無法產生回答、模型逾時或單一 Provider 限流屬於一般事件。跨 Provider 全部失敗、
權限繞過、回傳未授權文件或疑似金鑰外洩屬於重大事件。

## 第一時間處理

重大事件發現後十五分鐘內建立事件編號並通知值班負責人。處理人員先停止受影響
的工作流，保存 trace ID、Prompt 版本、文件版本與 Provider 錯誤類型，但不得把
API key、完整私人文件或使用者個資複製到事件說明。

## 復原

單一 Provider 暫時失敗時，可依核准的 Fallback 規則切換模型。證據不足、引用驗證
失敗或輸出格式不合格時，不得自動完成請求，必須轉入人工複核。復原後要重跑固定
評測集並確認沒有品質退化。
